# Smart Price Aggregator Backend

This directory houses the backend server for the Smart Price Aggregator. It serves product search comparisons using a combination of hand-verified static entries and bulk e-commerce items generated from real Kaggle datasets.

## Data Provenance & Compliance Notice

Our catalog is served from two local datasets:
1.  `manual_seed_dataset.json`: A manually curated database of verified products (like iPhone 15, Google Pixel 10) with verified live pricing.
2.  `kaggle_seed_dataset_generated.json`: A bulk catalog generated by downloading a public Amazon product dataset from Kaggle via the `kagglehub` API.

> [!IMPORTANT]
> **Synthetic Price Listing Notice**: For bulk items generated from Kaggle data (`kaggle_seed_dataset_generated.json`), each product contains a primary listing containing the real price sourced from the dataset. A second listing (labeled **"Flipkart (Estimated)"**) is **synthetically derived** by applying a randomized offset of ±3% to 8% to the primary price. 
>
> These secondary listings are generated for comparison demo purposes and do not represent independently crawled real-time prices.
